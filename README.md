# DeepTruth

> **In a world of lies, let DeepTruth be your eyes.**

DeepTruth is a production-grade AI-driven Trust Intelligence Operating System built with Flutter. It empowers users to verify news, investigate digital footprints, and separate truth from misinformation — all in real time, with deterministic consensus scoring.

## Features

- 🔍 **Truth Lens** — AI-powered fact-checking for news, claims, images, videos, and URLs
- 📰 **Trust Feed** — Curated news with AI summaries, share, and bookmark
- 🕵️ **TraceIQ** — OSINT toolkit for email breach checks, username lookups, IP tracing, and more
- 🤖 **AskIQ** — AI assistant for fact-based Q&A
- 🎬 **ReelIQ** — Reel & video claim verification
- 🔥 **Streak** — Gamified daily truth-checking with ranks and achievements
- 📄 **PDF Reports** — Generate and share verified intelligence reports
- 🛡️ **Evidence Vault** — De-duplicated cache with firstSeen/lastSeen tracking
- 📊 **Admin Dashboard** — Full analytics, API health, retention metrics

## Getting Started

### Prerequisites

- Flutter SDK 3.x+
- Firebase project configured (Firestore, Analytics, Crashlytics, Remote Config, FCM, Auth)
- Android Studio or Xcode

### Setup

1. **Clone the repo**
   ```bash
   git clone https://github.com/your-org/deeptruth.git
   cd deeptruth
   flutter pub get
   ```

2. **Configure API keys**
   
   Copy the template and add your keys:
   ```bash
   cp lib/core/constants/api_keys.dart.example lib/core/constants/api_keys.dart
   ```
   
   Or add keys via the in-app Settings → API Keys screen (stored in Hive).
   
   Alternatively, push keys via Firebase Remote Config (see `firebase_service.dart`).

   Required keys:
   | Key | Service | Free Tier |
   |-----|---------|-----------|
   | `gemini` | Google Gemini 2.0 Flash | Yes |
   | `news_api` | NewsAPI.org | 100 req/day |
   | `g_news` | GNews.io | 100 req/day |
   | `google_fact_check` | Google Fact Check API | Yes |
   | `google_cse_key` | Google Custom Search | 100 req/day |
   | `google_cse_cx` | Google CSE Engine ID | Yes |
   | `hibp` | HaveIBeenPwned | Paid |
   | `virus_total` | VirusTotal v3 | 500 req/day |
   | `urlscan` | URLScan.io | 100 req/day |

3. **Configure AdMob**
   
   For debug builds, test IDs are used automatically.
   
   For release builds, set your real AdMob App ID in `android/gradle.properties`:
   ```properties
   admobAppId=ca-app-pub-XXXXXXXXXXXXXXXX~XXXXXXXXXX
   ```
   
   Also update the production ad unit IDs in `api_keys.dart`.

4. **Configure Firebase**
   
   Place your `google-services.json` (Android) and `GoogleService-Info.plist` (iOS) in the appropriate directories.

5. **Run the app**
   ```bash
   flutter run
   ```

### Release Build

```bash
# Android
flutter build apk --release

# iOS
flutter build ios --release
```

> **Note**: Ensure you have configured a real signing key in `android/app/build.gradle.kts` before publishing.

## Architecture

- **Deterministic Scoring**: All trust scores, verdicts, and confidence values are generated by the on-device `ConsensusEngine`. Gemini is used ONLY for explanations and summaries.
- **Evidence Vault**: SHA-256 hash-based de-duplication with Firestore cloud cache and local Hive cache.
- **Plugin System**: Verification plugins (C2PA, Provenance, Deepfake, ThreatIntel, FactCheck, ReverseImage) run in parallel.
- **Rate Limiting**: UID-based daily scan limits via Firestore + Remote Config.

## Tech Stack

- **Framework**: Flutter (Dart)
- **AI**: Google Gemini 2.0 Flash (`google_generative_ai`)
- **Backend**: Firebase (Firestore, Analytics, Crashlytics, Remote Config, FCM, Auth)
- **Monetization**: Google AdMob
- **Local Storage**: Hive
- **Networking**: Dio + http
- **State**: Provider
- **News**: NewsAPI + GNews + Google Fact Check API
- **Threat Intel**: VirusTotal + URLScan.io + Wayback Machine

## Security

- `api_keys.dart` is in `.gitignore` — never committed
- API keys can be injected via Firebase Remote Config
- Anonymous authentication via Firebase Auth
- Rate limiting per UID
- GDPR/DPDP compliant (first-launch consent dialog)
